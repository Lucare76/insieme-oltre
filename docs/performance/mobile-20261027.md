## Modifiche

- Controller delle animazioni spostato in `DesktopScrollReveal`, importato solo se il boot script ha attivato le animazioni. Mobile e prefers-reduced-motion non scaricano quel chunk. Restano il fallback visibile dopo quattro secondi e il controllo delle ancore.
- Preload del logo con media query solo da 761 px. Srcset e sizes generati con getImageProps, uguali a quelli di next/image. Il logo resta un componente Image con gli stessi file, dimensioni, qualità e CSS. Su mobile usa il caricamento nativo lazy e la priorità automatica del browser.
- Nessuna modifica a contenuti, loghi, dipendenze, dati, autenticazione o cache del CMS.

## Misure

Il contenuto locale è quello predefinito del repository: non replica necessariamente i contenuti CMS in produzione. I JSON ridotti allegati conservano configurazione, audit e richieste di rete. ## Riproduzione

```sh
npm ci
npm run build
npm run start -- --hostname 127.0.0.1 --port 3033
# In un altro terminale, con Chrome disponibile:
npm exec --yes --package=lighthouse@13.5.0 -- lighthouse http://127.0.0.1:3033 --chrome-flags="--headless --no-sandbox --disable-dev-shm-usage" --only-categories=performance --output=json --output-path=mobile.json
```

Per confronto usare lo stesso Chrome, configurazione, contenuti e macchina, ripetendo entrambe le revisioni. L'ambiente corrente non consente di trasferire i tempi localhost direttamente al sito pubblico.
